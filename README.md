# AWS-Projects-
First Amazon EC2 Instance Launch Walkthrough
Overview
This repository hosts the recording of my first-ever launch of an Amazon EC2 (Elastic Compute Cloud) instance. This project serves as a foundational demonstration of my ability to provision and configure virtual servers in the AWS cloud environment.

Key Takeaways & Skills Demonstrated
The video visually walks through the entire process, demonstrating several fundamental cloud and technical skills:

AWS Management Console Navigation: Successfully navigating the AWS interface to locate and utilize the EC2 service.

Instance Launch Process: Following the correct workflow to launch a new virtual server.

AMI Selection: Choosing a suitable Amazon Machine Image (AMI) (e.g., Amazon Linux 2 or Ubuntu) for the instance.

Instance Type Selection: Selecting a free-tier eligible Instance Type (e.g., t2.micro).

Key Pair Generation: Creating and securely downloading a Key Pair (.pem file) for secure SSH access.

Security Group Configuration: Setting up a Security Group to act as a virtual firewall, ensuring only necessary ports (like SSH on port 22) are open.

Instance Connection (Optional, but good to mention): Briefly demonstrating or mentioning the connection to the running instance via SSH.

Resource Management: Terminating the instance to avoid unwanted charges and practice responsible cloud resource management.

Why This Matters
Launching an EC2 instance is a core foundational skill for any Cloud Engineer or Developer working with AWS. This video documents my initial hands-on experience and proficiency in setting up compute resources, which is essential for deploying applications, hosting websites, and running development environments in the cloud.
